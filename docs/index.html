SSH Commander

A secure SSH / SFTP client for Android, Windows and Linux.
Terminal, tabs, real‑time monitoring, built‑in editor, biometric lock.

Terminal

  • Full VT100 / ANSI emulation
  • Colors, block cursor, auto‑scroll
  • Control key panel (ESC, arrows, TAB, Ctrl+…)
  • Zoom text with Ctrl + mouse wheel

SFTP + Editor

  • Browse server file system
  • Built‑in text editor for configs & scripts
  • Upload, download, delete, rename
  • Preview files without downloading

Monitoring

  • CPU, RAM, Disk usage widgets
  • Real‑time logs (tail -f)
  • Quick commands with categories
  • Variables for templated commands

Workspaces & Tabs

  • Save and restore session layouts
  • Pin important tabs
  • Color‑coded tabs for environments
  • Full session persistence
