**SSH COMMANDER**

---

**SSH Commander** — мощный клиент для удалённого управления серверами по SSH и SFTP с терминалом, виджетами и биометрической защитой.

> **Текущая версия:** 1.5 — первоначальная настройка и гайд по приложению, поддержка Windows и Linux.

![Скриншот приложения](ScreenShots/screenshot.png)

SSH Commander — мощный и удобный кроссплатформенный клиент для удалённого управления серверами по SSH и SFTP — доступен на **Android**, **Windows** и **Linux**. Создан для системных администраторов, DevOps-инженеров и всех, кто работает с удалёнными серверами.

## Возможности

### Бессмертные фоновые сессии (Новое в 1.7.0)
- **Непрерывность сессий** — соединения теперь живут в глобальном `SessionManager`. Переходите в настройки или переключайте приложения без потери SSH/SFTP соединения.
- **Фоновая работа на Android** — стабильные подключения, которые выживают при пересоздании интерфейса и навигации по системе.
- **Умный авто-реконнект** — интеллектуальная логика повторных попыток с экспоненциальной задержкой (2с, 4с, 8с...) для обработки нестабильных сетей.

### Умные рабочие пространства и вкладки
- **Workspaces (Рабочие пространства)** — сохраняйте всё окружение целиком (открытые серверы, конкретные пути в SFTP и последние команды) и восстанавливайте его одним нажатием.
- **Глобальная синхронизация** — рабочие пространства теперь включены в бэкап и облачную синхронизацию, появляясь на всех ваших устройствах.
- **Вкладки сессий** — запускайте несколько независимых сессий для одного сервера (кнопка «+»).
- **Организация** — закрепляйте вкладки и назначайте цвета (например, Красный для Production, Синий для Development).

### Кроссплатформенный SFTP-менеджер
- **Единый движок** — полностью переработанное ядро SFTP, которое работает одинаково стабильно на Android (SAF) и Desktop.
- **Встроенный редактор** — редактируйте конфигурационные файлы прямо на сервере и сохраняйте мгновенно.
- **Умные передачи** — надежная загрузка и скачивание с отслеживанием прогресса и поддержкой нескольких файлов.
- **Удаленный предпросмотр** — просмотр текста, JSON и изображений без предварительного скачивания.
- **Ручная навигация** — быстрый переход по любому пути через ввод с клавиатуры.

### Identity Master и SSH-ключи
- **Единые Личности** — управляйте учетными данными и SSH-ключами в одном месте.
- **Генератор ключей** — создавайте безопасные ключи RSA-4096 или Ed25519 прямо в приложении.
- **Авто-провижининг** — автоматически развертывайте свои публичные ключи на удаленных серверах одним кликом.
- **Проверка Host Key** — защита от атак типа Man-in-the-Middle.

### Мониторинг и командный центр
- **Дашборд в реальном времени** — виджеты нагрузки CPU, RAM и диска + живой стриминг логов (`tail -f`).
- **Умные сниппеты** — кастомные команды с поддержкой переменных `{{var}}` и фильтрацией по категориям.
- **Виджеты на главном экране** — (Android) проверяйте статус серверов и запускайте команды, не открывая приложение.

### Безопасность и конфиденциальность
- **Биометрический замок** — защита приложения по отпечатку пальца или Face ID.
- **Безопасное хранилище** — шифрование всех чувствительных данных с использованием системных провайдеров (DPAPI на Windows).
- **Режим инкогнито** — маскировка IP-адресов в списках для безопасных презентаций или скриншотов.

## Платформы

- **Android** — полнофункциональный мобильный клиент с виджетами на главном экране и биометрической блокировкой.
- **Windows** — десктопный клиент с изменяемыми панелями, разделённым видом «Терминал + SFTP» и установщиками MSI/EXE.
- **Linux** — десктопный клиент для Linux-систем (протестировано на Debian/Ubuntu), поддержка пакетов DEB и RPM.

## Требования

- **Android 7.0** (API level 24) или выше.
- **Windows 10** или выше.
- **Linux** (современные дистрибутивы: Ubuntu 22.04+, Debian 11+, Fedora и др.).

## Установка

### Из GitHub Releases
1. Перейдите в [Releases](https://github.com/Neytron951/SSHCommander/releases)
2. Скачайте последний `.apk` (Android), `.msi`/`.exe` (Windows) или `.deb`/`.rpm` (Linux)
3. Установите

### Из исходников
```bash
git clone https://github.com/Neytron951/SSHCommander.git
cd SSHCommander

# Android-приложение
./gradlew :androidApp:assembleDebug

# Windows-десктоп (установщик MSI или EXE)
./gradlew :desktopAppWindows:packageMsi
./gradlew :desktopAppWindows:packageExe

# Или соберите оба установщика интерактивным скриптом
# (спросит имя и версию, готовые .msi/.exe положит в папку dist\)
build-windows.bat

# Windows-десктоп — папка без установки
./gradlew :desktopAppWindows:createDistributable

# Запуск десктопного приложения для разработки
./gradlew :desktopAppWindows:run
./gradlew :desktopAppLinux:run

# Сборка Linux-пакетов (DEB или RPM)
./gradlew :desktopAppLinux:packageDeb
./gradlew :desktopAppLinux:packageRpm

# Или используйте скрипт сборки для Linux
chmod +x build-linux.sh
./build-linux.sh

# Тесты
./gradlew :shared:desktopTest
```
