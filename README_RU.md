**SSH COMMANDER**

---

**SSH Commander** — мощный клиент для удалённого управления серверами по SSH и SFTP с терминалом, виджетами и биометрической защитой.

> **Текущая версия:** 1.4 — предпросмотр и выбор файлов в SFTP, разделённый вид «Терминал + SFTP», установщики Windows (MSI/EXE)

![Скриншот приложения](ScreenShots/screenshot.png)

SSH Commander — мощный и удобный кроссплатформенный клиент для удалённого управления серверами по SSH и SFTP — доступен на **Android** и **Windows**. Создан для системных администраторов, DevOps-инженеров и всех, кто работает с удалёнными серверами.

## Возможности

### Полноценный терминал
- Полная эмуляция VT100/ANSI с поддержкой цветов — nano, vim, htop работают корректно
- Панель управляющих клавиш: ESC, стрелки, TAB, Ctrl+X/O/G/W/K
- Удержание клавиш с автоповтором, блочный курсор, автоскролл
- Настраиваемый шрифт и размер текста для комфортной работы
- Десктоп: масштабирование текста терминала колёсиком мыши с Ctrl
- Исправлена работа стрелок истории под не-root пользователем
- Выделение и копирование текста из консоли

### Сессии и вкладки
- **Вкладки сессий** на Android и Windows — открывайте столько сессий, сколько нужно
- **Несколько сессий на сервер** — вторая (третья, …) сессия для того же сервера кнопкой «+»
- **Полное сохранение состояния сессий** — сверните приложение, переключите сервер или вкладку; каждая сессия хранит своё состояние до закрытия приложения
- Горизонтальная прокрутка вкладок — большое количество открытых сессий никогда не станет проблемой
- Один клик закрывает сессию и освобождает соединение

### SFTP-файловый менеджер
- Просмотр и навигация по файловой структуре сервера
- Загрузка и скачивание файлов, создание папок, переименование и удаление
- Поиск по файлам, отображение скрытых файлов, мультивыбор
- Настраиваемая стартовая папка для быстрого доступа
- **Предпросмотр файлов без скачивания** — текст, JSON и изображения открываются сразу; бинарники (EXE/RAR/ZIP/MSI) заблокированы
- **Механика выделения:** один клик — выбор, Ctrl+клик — доп. выбор, Shift+клик — диапазон, двойной клик — предпросмотр / переход в папку, правый клик — контекстное меню со скачиванием
- **Выбор папки для скачивания** вместо молчаливого сохранения в домашнюю директорию
- **Ручной ввод пути** с клавиатуры (например `/var/www/site`)

### Разделённый вид (Терминал + SFTP)
- Окно делится 50/50 с перетаскиваемой границей — размеры панелей настраиваются перетаскиванием
- Панель быстрых команд доступна и в разделённом режиме

### Быстрые команды и виджеты
- Готовые команды: df -h, free -m, htop, uptime, ps aux, tail -f
- Создание собственных команд с подтверждением и биометрией для опасных действий
- Виджет на главный экран Android: статус серверов (онлайн/оффлайн) и быстрый запуск команд

### Безопасность
- Блокировка приложения по отпечатку пальца или Face ID
- Проверка смены host-ключа (защита от Man-in-the-Middle)
- Режим конфиденциальности — скрытие части IP-адресов в списке

### Гибкость и настройки
- Неограниченное количество серверов с группировкой по папкам и иконками
- Папки можно создавать, переименовывать и удалять на обеих платформах
- Несколько логинов для каждого сервера
- Светлая и тёмная тема, настройка внешнего вида терминала
- Автопереподключение при обрыве связи
- Резервное копирование данных (экспорт/импорт JSON, совместимо между Android и десктопом)
- Поддержка русского и английского языков

## Платформы

- **Android** — полнофункциональный мобильный клиент с виджетами на главном экране и биометрической блокировкой
- **Windows** — десктопный клиент с изменяемыми панелями, разделённым видом «Терминал + SFTP», меню и экспортом/импортом. Устанавливается в **Program Files** с ярлыком в **меню Пуск** — Windows находит приложение поиском и в списке приложений.

## Требования

- **Android 7.0** (API level 24) или выше
- **Windows 10** или выше (для десктопной версии)

## Установка

### Из GitHub Releases
1. Перейдите в [Releases](https://github.com/Neytron951/SSHCommander/releases)
2. Скачайте последний `.apk` для Android или `.msi` / `.exe` для Windows
3. Установите (на Android разрешите установку из неизвестных источников)

### Из исходников
```bash
git clone https://github.com/Neytron951/SSHCommander.git
cd SSHCommander

# Android-приложение
./gradlew :androidApp:assembleDebug

# Windows-десктоп (установщик MSI или EXE)
./gradlew :desktopApp:packageMsi
./gradlew :desktopApp:packageExe

# Или соберите оба установщика интерактивным скриптом
# (спросит имя и версию, готовые .msi/.exe положит в папку dist\)
build-windows.bat

# Windows-десктоп — папка без установки
./gradlew :desktopApp:createDistributable

# Запуск десктопного приложения для разработки
./gradlew :desktopApp:run

# Тесты
./gradlew :shared:desktopTest
```
