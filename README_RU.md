**SSH COMMANDER**

---

**SSH Commander** — мощный клиент для удалённого управления серверами по SSH и SFTP с терминалом, виджетами и биометрической защитой.

> **Текущая версия:** 1.9.1 — Маркет скриптов, оптимизация мобильного UI, поддержка Windows и Linux.

![Скриншот приложения](ScreenShots/screenshot.png)

SSH Commander — мощный и удобный кроссплатформенный клиент для удалённого управления серверами по SSH и SFTP — доступен на **Android**, **Windows** и **Linux**. Создан для системных администраторов, DevOps-инженеров и всех, кто работает с удалёнными серверами.

## Возможности

### Маркет скриптов (Новое в 1.9.0)
- **Централизованный репозиторий** — просматривайте и устанавливайте скрипты сообщества прямо из приложения.
- **Автоматическая синхронизация** — бэкенд обновляется напрямую из GitHub, обеспечивая мгновенный доступ к новым рецептам.
- **Умные шаблоны** — поддержка синтаксиса {{VARIABLE}} в скриптах для запроса значений перед выполнением.
- **Категоризация** — фильтрация скриптов по категориям: Голосовые серверы, VPN, Мониторинг, Утилиты и другие.

### Продвинутый мобильный UI (Новое в 1.9.1)
- **Режим фокуса** — автоматическое скрытие шапки и вкладок при открытой клавиатуре для максимального расширения области терминала.
- **Компактная панель управления** — единая прокручиваемая лента со всеми важными клавишами (Esc, Tab, Ctrl, Стрелки) прямо над клавиатурой.
- **Ландшафтный Sidebar** — вертикальная панель управления для горизонтального режима, освобождающая всю высоту экрана под консоль.
- **Интеллектуальные вкладки** — удаление избыточных названий серверов из заголовка для экономии места.

### Бессмертные фоновые сессии
- **Непрерывность сессий** — соединения живут в глобальном SessionManager. Переходите в настройки или переключайте приложения без потери связи.
- **Фоновая работа на Android** — стабильные подключения, которые выживают при пересоздании интерфейса и навигации.
- **Умный авто-реконнект** — интеллектуальная логика повторных попыток с экспоненциальной задержкой.

### Умные рабочие пространства и вкладки
- **Workspaces** — сохраняйте всё окружение целиком (открытые серверы, пути в SFTP и последние команды) и восстанавливайте его одним нажатием.
- **Глобальная синхронизация** — рабочие пространства включены в облачную синхронизацию и доступны на всех устройствах.
- **Вкладки сессий** — запускайте несколько независимых сессий для одного сервера.
- **Организация** — закрепляйте вкладки и назначайте им цвета.

### Кроссплатформенный SFTP-менеджер
- **Единый движок** — ядро SFTP работает одинаково стабильно на Android (SAF) и Desktop.
- **Встроенный редактор** — редактируйте конфигурационные файлы прямо на сервере.
- **Умные передачи** — надежная загрузка и скачивание с отслеживанием прогресса.
- **Удаленный предпросмотр** — просмотр текста, JSON и изображений без предварительного скачивания.

### Identity Master и SSH-ключи
- **Единые Личности** — управляйте учетными данными и SSH-ключами в одном месте.
- **Генератор ключей** — создавайте безопасные ключи RSA-4096 или Ed25519 прямо в приложении.
- **Авто-провижининг** — автоматическое развертывание публичных ключей на серверах.

### Мониторинг и командный центр
- **Дашборд в реальном времени** — виджеты нагрузки CPU, RAM и диска + живой стриминг логов.
- **Умные сниппеты** — кастомные команды с поддержкой переменных и фильтрацией.
- **Виджеты на главном экране** — (Android) проверка статуса серверов и запуск команд без открытия приложения.

### Безопасность и конфиденциальность
- **Биометрический замок** — защита приложения по отпечатку пальца или Face ID.
- **Безопасное хранилище** — шифрование данных с использованием системных провайдеров (DPAPI на Windows).
- **Режим инкогнито** — маскировка IP-адресов для безопасных презентаций или скриншотов.

## Платформы

- **Android** — полнофункциональный мобильный клиент с виджетами и биометрической блокировкой.
- **Windows** — десктопный клиент с разделенным видом и MSI/EXE установщиками.
- **Linux** — десктопный клиент для Linux-систем. Протестировано на Debian/Ubuntu (DEB/RPM) и Arch Linux (нативная сборка с оптимизацией под Hyprland).

## Требования

- **Android 7.0** (API level 24) или выше.
- **Windows 10** or higher.
- **Linux** (Ubuntu, Debian, Arch Linux и др.).

## Установка

### Из GitHub Releases
1. Перейдите в [Releases](https://github.com/Neytron951/SSHCommander/releases)
2. Скачайте последний `.apk` (Android), `.msi`/`.exe` (Windows) или `.deb`/`.rpm` (Linux)
3. Установите

### Из исходников

#### Android
```bash
./gradlew :androidApp:assembleRelease
```

#### Windows
```bash
# Автоматическая сборка установщиков MSI и EXE:
build-windows.bat

# Или ручная сборка:
./gradlew :desktopAppWindows:packageMsi
./gradlew :desktopAppWindows:packageExe

# Запуск для разработки:
./gradlew :desktopAppWindows:run
```

#### Linux (Debian, Ubuntu, Fedora)
```bash
# Автоматическая сборка пакетов DEB и RPM:
./build-linux.sh

# Или ручная сборка:
./gradlew :desktopAppLinux:packageDeb
./gradlew :desktopAppLinux:packageRpm
```

#### Linux (Arch, Manjaro)
```bash
# Сборка, установка и создание ярлыка:
./install-arch.sh

# Или просто сборка папки с приложением:
./gradlew :desktopAppLinux:createDistributable

# Запуск для разработки:
./gradlew :desktopAppLinux:run
```
